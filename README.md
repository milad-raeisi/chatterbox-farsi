# آوا · استودیوی صدای فارسی

تبدیل متن فارسی به گفتار طبیعی با مدل [Chatterbox Farsi](https://huggingface.co/mehdi-hf/chatterbox-farsi)، **کاملاً آفلاین** و روی دستگاه خودتان. رابط کاربری با [Animate UI](https://animate-ui.com) ساخته شده است.

- **کاملاً آفلاین:** پس از یک بار دریافت مدل، هیچ اتصالی به اینترنت لازم نیست. مدل، فونت، رابط کاربری و فایل‌ها همه روی همین دستگاه‌اند و هیچ متن یا صدایی جایی فرستاده نمی‌شود.
- **دو صدای آماده** (زن و مرد) و **ساخت صدای شخصی** از یک نمونهٔ ۵ تا ۱۰ ثانیه‌ای: ضبط با میکروفون یا بارگذاری فایل.
- **متن بلند:** متن به‌طور خودکار جمله‌به‌جمله بخش می‌شود و پیشرفت ساخت، بخش‌به‌بخش نمایش داده می‌شود.
- **یکسان‌سازی متن فارسی:** «ي/ك» عربی به «ی/ک» تبدیل می‌شود و اعداد به حروف خوانده می‌شوند (۱۴۰۲ ← هزار و چهارصد و دو؛ شماره‌ها رقم‌به‌رقم).
- **کنترل لحن:** سبک‌های آماده (متعادل، آرام، پرانرژی، یکنواخت)، بیان احساس، آهنگ گفتار، تنوع، مکث بین جمله‌ها و «بذر» برای نتیجهٔ تکرارپذیر.
- **پخش‌کننده با شکل موج**، تغییر سرعت پخش، دانلود WAV و تاریخچهٔ ساخته‌ها.
- راست‌به‌چپ کامل، ارقام فارسی، پوستهٔ روشن و تیره، سازگار با موبایل.

## پیش‌نیازها

| | |
|---|---|
| [uv](https://docs.astral.sh/uv/) | پایتون ۳٫۱۱ را خودش نصب می‌کند |
| Node.js ۲۰ یا بالاتر | فقط برای ساختن رابط کاربری؛ برای اجرا لازم نیست |
| فضای دیسک | حدود ۴ گیگابایت برای مدل و ۳ گیگابایت برای PyTorch |
| حافظه | دست‌کم ۸ گیگابایت RAM |

## نصب (فقط یک بار، با اینترنت)

۱. در صفحهٔ [mehdi-hf/chatterbox-farsi](https://huggingface.co/mehdi-hf/chatterbox-farsi) وارد حساب Hugging Face شوید و مجوز مدل را بپذیرید.

۲. وابستگی‌ها و مدل را دریافت کنید و رابط کاربری را بسازید:

```bash
make setup                         # uv sync + npm install + ساخت رابط کاربری
cd backend && uv run hf auth login # یک توکن با دسترسی read
make models                        # دریافت مدل در backend/models/chatterbox-farsi
```

بدون `make`:

```bash
cd backend && uv sync && uv run hf auth login && uv run python scripts/download_models.py
cd ../web && npm install && npm run build
```

## اجرا (آفلاین)

```bash
make start      # یا: cd backend && uv run python -m app --open
```

سپس <http://127.0.0.1:8000> را باز کنید. کل برنامه یک فرایند محلی است و سرور پایتون رابط کاربری را هم ارائه می‌دهد. بار اول بارگذاری مدل در حافظه چند ثانیه طول می‌کشد.

برای اجرا روی دستگاهی دیگر بدون اینترنت، پوشهٔ `backend/models/chatterbox-farsi` را کپی کنید و مسیرش را با `AVA_MODEL_DIR` بدهید.

## سرعت

| سخت‌افزار | سرعت تقریبی |
|---|---|
| کارت گرافیک انویدیا (CUDA) | نزدیک به زمان واقعی روی T4 (طبق کارت مدل) |
| CPU (Apple M5 Pro) | حدود ۲٫۵ تا ۳٫۵ برابر کندتر از زمان واقعی |
| Apple MPS | حدود ۵٫۷ برابر کندتر، و به گفتهٔ سازندهٔ مدل با کیفیت پایین‌تر |

به همین دلیل حالت خودکار روی مک از CPU استفاده می‌کند. MPS فقط با `AVA_DEVICE=mps` فعال می‌شود.

## توسعه

```bash
make dev    # API روی :8000 با بارگذاری خودکار + Next.js روی :3000
make test   # تست‌های بک‌اند + lint و type-check رابط کاربری
```

### تنظیمات (متغیرهای محیطی)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `AVA_MODEL_DIR` | `backend/models/chatterbox-farsi` | پوشهٔ فایل‌های مدل |
| `AVA_DATA_DIR` | `backend/data` | صداهای ساخته‌شده و خروجی‌ها |
| `AVA_DEVICE` | `auto` | `auto`، `cuda`، `cpu` یا `mps` |
| `AVA_HOST` / `AVA_PORT` | `127.0.0.1` / `8000` | نشانی سرور |
| `AVA_CHUNK_CHARS` | `180` | حداکثر طول هر بخش متن |
| `AVA_MAX_TEXT_CHARS` | `5000` | حداکثر طول متن ورودی |
| `AVA_T3_CHECKPOINT` | — | استفاده از فایل وزن T3 دیگر |

### ساختار پروژه

```
backend/   سرور FastAPI و موتور مدل (پایتون، uv)
  app/       engine.py · text.py · voices.py · main.py
  scripts/   download_models.py: تنها بخشی که به اینترنت نیاز دارد
  tests/
web/       رابط کاربری Next.js + Tailwind + shadcn/ui + Animate UI (خروجی ایستا در web/out)
```
